# 太仓耐克 ASRS 自动化仓库 — RW Phase II 施工总览（看板分享版）

本仓库托管的是 **RW Phase II 施工总览** 看板的静态分享版本（对应本地 `RW_PhaseII_施工总览_v1.3.html`）。

## 在线查看

https://zhaohuahua-sys.github.io/taicang-nike-asrs-dashboard/

任何人拿到上面的链接即可直接打开查看，无需登录。

## 数据更新权限
- 看板数据由**项目管理员（仓库所有者）**维护与更新；只有管理员能向本仓库推送新版本，其他人无法修改共享数据。
- 看板内的「选择 Excel 更新看板」按钮：访客点击后只会把**自己电脑上的 Excel** 加载到**其本人浏览器**里做本地预览，**不会影响**本仓库 / Pages 上的共享看板。
- 如需更新共享看板，管理员在本地修改源 Excel 后重新生成 v1.3，再推送本仓库即可。

## 内容说明
- 一屏总览：KPI、关键里程碑时间线、全项目甘特图（含本周高亮带）、本周与下周计划。
- 里程碑含 SIT 系统集成测试、UAT 用户验收测试、爬坡试运行、系统最终验收、项目上线等，时间随源 Excel 更新。
